## Month 1~2: VBT 측정 정확도 고도화

### 목표
측정 데이터의 신뢰도를 높여 사용자가 수치를 믿고 활용할 수 있도록 함

### 주요 기능

| 기능 | 설명 | 사용자 가치 |
|------|------|------------|
| **데이터 정제** | 장비 진동, 노이즈 필터링 개선 | "측정값이 들쭉날쭉하지 않네" |
| **유효 렙 판정 개선** | 반쪽짜리 동작, 튕기는 동작 필터링 | "제대로 한 것만 카운트되네" |
| **품질 지표 세분화** | 가동범위 일관성, 템포 분석 추가 | "어디가 부족한지 구체적으로 알겠네" |

### 예시 화면
```
동작 품질: 82점
├─ 가동범위: 95% (일관성 우수)
├─ 템포: 78% (내리는 동작이 너무 빠름)
└─ 좌우 균형: 88%
```

## Month 3: 맞춤형 목표 설정

### 목표
"다음에 뭘 해야 하지?" 고민 없이, AI가 현실적인 목표를 제안

### 주요 기능

| 기능 | 설명 | 사용자 가치 |
|------|------|------------|
| **성장 트렌드 분석** | 최근 4-8주 운동 기록에서 성장률 계산 | "한 달간 벤치 5% 성장했네" |
| **다음 목표 제안** | 성장률 + 안전 마진 적용한 현실적 목표 | "다음 주 목표가 뭔지 바로 보이네" |
| **달성 확률 표시** | 목표 난이도를 직관적으로 표현 | "무리한 목표인지 아닌지 알겠네" |

### 예시 화면
```
📈 이번 주 목표

벤치프레스: 82.5kg × 8회
├─ 지난 주: 80kg × 8회 달성
├─ 성장률: +2.5kg/주
└─ 달성 확률: 85% 🟢

스쿼트: 100kg × 6회
├─ 지난 주: 100kg × 5회 달성
├─ 성장률: +1회/주
└─ 달성 확률: 70% 🟡
```

### 엣지 케이스
- **신규 사용자**: 일반적인 초보자 기준 목표 제안
- **장기 휴식 후 복귀**: 이전 대비 낮은 목표로 안전하게 시작

## Month 4: AI 챗봇 (세션 분석)

### 목표
자연어로 운동 데이터를 질문하고 즉각적인 피드백을 받을 수 있도록 함

### 주요 기능

| 기능 | 설명 | 사용자 가치 |
|------|------|------------|
| **세션 분석 대화** | "오늘 스쿼트 어땠어?" → 세트별 분석 | "복잡한 데이터를 쉽게 이해하겠네" |
| **데이터 조회** | "이번 주 운동량은?", "PR 언제 세웠어?" | "기록 찾으려고 뒤적일 필요 없네" |
| **비교 분석** | "지난달이랑 비교해줘" | "성장했는지 바로 알겠네" |

### 예시 대화
```
👤 오늘 스쿼트 분석해줘

🤖 오늘 스쿼트 3세트 분석 결과예요.

📊 세트별 요약
• 1세트: 80kg, 여유 있음 (RIR 4)
• 2세트: 80kg, 적당함 (RIR 3)
• 3세트: 80kg, 힘들었음 (RIR 1)

💡 총평
피로도가 적절히 누적됐어요.
근비대 훈련에 딱 맞는 강도였습니다! 👍
```

## Month 5: AI 챗봇 완성 (실시간 코칭)

### 목표
단순 분석을 넘어 **실시간 위험 감지 + 구체적 행동 권장**

### 주요 기능

| 기능 | 설명 | 사용자 가치 |
|------|------|------------|
| **Velocity Loss 경고** | 피로 누적 시 즉시 알림 | "위험할 때 멈추라고 알려주네" |
| **중량 권장** | RIR 기반 다음 세트 중량 제안 | "얼마로 해야 할지 고민 안 해도 되네" |
| **부상 예방 조언** | 좌우 불균형, 과도한 피로 경고 | "다치기 전에 미리 알려주네" |

### 예시 대화
```
👤 다음 세트 중량은?

🤖 현재 3세트까지 분석했어요.

📊 현재 상태
• RIR: 2 (적당한 여유)
• 피로도: 28% (정상 범위)

💪 권장
다음 세트 2.5kg 증량 도전해보세요!
80kg → 82.5kg
```

```
🤖 ⚠️ 알림

피로도가 62%에 도달했어요.
근비대 목표(20-30%)를 초과했으니
이번 세트에서 마무리하세요!
```
